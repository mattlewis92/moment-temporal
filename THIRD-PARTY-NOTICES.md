# Third-party notices

moment-temporal reimplements the public APIs of moment.js and
moment-timezone. It additionally incorporates from those projects: locale
configuration files, parsing/formatting token tables, the packed timezone
data format and its pack/unpack utilities, timezone data files, and the
complete test suites. Original copyright headers are preserved in vendored
files.
